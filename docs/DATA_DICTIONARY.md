# Data dictionary

All records are **synthetic** (`synthetic: true`). Dataset: 102 entities, 240 relationships (232 `supply`, 8 `financial`), generated by `backend/data/generate_dataset.py` (seed 20261009).

## Entity (`fnb_entities.json`)
| Field | Type / range | Meaning |
|---|---|---|
| id, name | string | Stable id; invented name |
| synthetic | bool | Always true here |
| entity_type | enum | agricultural_producer, agricultural_input, processor, manufacturer, packaging_supplier, cold_storage, transport_operator, port_hub, distribution_centre, wholesaler, retailer, utility, financial |
| food_category | string | grains, rice, sugar, coffee, cocoa, dairy, fruit_veg, edible_oils, beverages, packaging, logistics, retail_distribution, prepared_foods, agri_inputs, energy, finance |
| output_product | string / null | Product supplied (null for retailers) |
| country, region | string | Real place names used for plausibility only |
| latitude, longitude | float / null | Approximate **synthetic** location; null for the 2 financial entities (`location_status: missing_headquarters_only`) |
| facility_type | string | Descriptive |
| revenue_musd, value_added_musd | ≥ 0 | Synthetic economic proxies (USD million/yr); value added = revenue × type ratio; losses use value added |
| capacity_tonnes_per_year | float / null | revenue ÷ indicative price; null for services |
| inventory_days | 0–365 | Days of input stock |
| alternative_supplier_availability | 0–1 | Ease of switching suppliers for the entity's inputs |
| operational_criticality | 0–1 | Systemic score input |
| spare_capacity_fraction | 0–1 | Used for capacity-limited alternative sourcing |
| exposed_asset_share | 0–1 / null | Exposure E in the direct-loss formula |
| flood/heat/drought_vulnerability | 0–1 | Vulnerability V per hazard (archetype + jitter) |
| provenance, confidence | string, low/medium/high | Always "synthetic"; low |
| in_demo_portfolio | bool | Member of the 18-holding synthetic portfolio |
Missing values are explicit (`null`) and counted at `/api/v1/data/quality`.

## Relationship (`fnb_relations.json`)
| Field | Meaning |
|---|---|
| id, source, target | `source->target`; direction supplier → customer |
| product | The source's `output_product` |
| channel | `supply` (propagated) or `financial` (displayed only) |
| relationship_type | raw_material_supply, agri_input_supply, product_supply, packaging_supply, logistics_service, utility_supply, finance_or_insurance |
| dependency | Share (0–1) of the target's input of that product; Σ ≤ 1 per (target, product) |
| input_specificity | 0–1 essentiality of the input |
| substitutability | 0–1 ease of substituting a different input |
| storable, lead_time_days | Whether stock can buffer it; pipeline days (0 for non-storable) |
| annual_flow_musd | Synthetic flow = dependency × customer input spend |
| distance_km | Haversine between synthetic locations |
| status | disclosed / inferred / **synthetic** / modelled (mitigation-created) |
| confidence | 0–1 plausibility of the stylised pattern (not a measurement) |
| provenance | Text |

## Scenario (`scenarios.json`, DB `scenarios`)
`hazards[]` (hazard_type, intensity index 0–1, duration_days, footprint centre/radius **or** regions **or** affected_entity_ids), `time_horizon_year` (label), `propagation_max_depth`, `inventory_scale`, `substitution_scale`, `dependency_scale`, `compound_amplification`, `monte_carlo_runs`, `monte_carlo_seed`.

## Validation rules (`domain/dataset.py`)
Duplicate ids; unknown/self-referencing edges; duplicate edges; Σdependency > 1 per input; value added > revenue; half-set coordinates (errors) · isolated nodes; missing coordinates; cycles (warnings, kept and explained).
